KRUPA H N — DESIGN PORTFOLIO

HOW TO OPEN
1. Extract this ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

IMPORTANT BEFORE SHARING
- Replace images/profile-placeholder.svg with a clear photo showing your face. You can save your photo as images/profile.jpg and update the image path in index.html.
- The six project thumbnails in images/ are sample concept visuals. Create your own actual designs in Figma/Canva and replace these sample thumbnails before presenting them as completed work.
- Update the email address in index.html if needed.
- The project descriptions are concept descriptions; do not claim work you have not completed.

PUBLISHING
You can publish this website with GitHub Pages:
1. Create a GitHub repository.
2. Upload all files and the images folder.
3. In repository Settings > Pages, choose Deploy from a branch and select main / root.
4. Save and wait for the public website link.

For SeeMyWorks, upload your real project images/design exports and use public image links where their platform asks for them. This ZIP is a starter website, not an already-published SeeMyWorks portfolio.
